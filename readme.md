# Hotel Reservation System

A Java console-based hotel reservation application developed for the CodeAlpha Java Programming Internship.

## Features

- View available rooms
- Book rooms
- Cancel bookings
- Room categorization (Standard, Deluxe, Suite)
- Payment simulation
- View booking details

## Technologies Used

- Java
- OOP (Object-Oriented Programming)
- ArrayList

## How to Run

Compile:

```bash
javac HotelReservationSystem.java
```

Run:

```bash
java HotelReservationSystem
```
